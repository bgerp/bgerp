# Обединяване на CSS и JavaScript

`compactor` е собствен bgERP плъгин, а не обвивка на външна библиотека. Няма външно
издание за обновяване. Версията на Setup и глобалните списъци `COMPACTOR_JS_FILES` и
`COMPACTOR_CSS_FILES` остават непроменени.

## Поправки

- Кеш ключът включва пътищата, реда, времето и размера на входните SBF файлове.
  Различни файлове с еднакъв `mtime` вече не споделят погрешно един bundle.
- Между JS файловете се добавя `;` на нов ред. Така израз без финална точка и запетая
  не се слива със следващ IIFE. Пред първия файл няма добавен `;`, за да се запази
  началният `"use strict"`.
- При script обект се запазва оригиналният списък, включително атрибути, CDN fallback
  и ред. За такъв списък обединяването се пропуска, което може да увеличи броя заявки.
- При липса на всички входни файлове не се връща адрес на празен bundle.
  При неуспешно прочитане/записване се връща оригиналният списък.
- Относителните CSS `url()` адреси запазват query и fragment след SBF преобразуването.
  Външни, `data:`, абсолютни и fragment адреси остават непроменени.

Подреждането по конфигурацията и добавянето на jQuery Migrate след jQuery се запазват.
Не са добавяни зависимости, миграции или промени в настройките на други инсталации.
Новият формат на кеш ключа отделя bundle-ите от генерираните със стария код.

## Проверки и ограничения

```sh
php compactor/tests/bundles.php
php jquery/tests/loading.php
```

И на PHP 7.4, и на PHP 8.2 преминават 17 compactor проверки и 12 проверки на jQuery
зареждането. Покрити са колизии при еднакво време, промяна на реда, стабилен ключ,
JS граници, начален strict mode, script обекти, празни/липсващи входове, неуспешно
създаване на директория, изчезнал вход преди прочитане и CSS адреси.

В браузъра са проверени обединени синтетични JS/CSS файлове през стандартния SBF
pipeline и двата избора в minify на PHP 7.4 и 8.2. За повторение използвайте
[сценария за minify](../minify/README.md#проверки), включително последователните JS
файлове и изображение с query/fragment.

Това остава конкатенация на конфигурирани ресурси, не module bundler. Файловете трябва
да са подходящи за общ JS scope; например отделни directive prologues не могат да
запазят различен strict mode за всяка част. CSS преобразуването остава по досегашния
регулярен израз, не е пълен CSS parser. Кешът не открива подмяна на съдържание, при
която пътят, размерът и `mtime` са умишлено запазени. Не са симулирани прекъсване на
диска или едновременни записи от много web workers.
