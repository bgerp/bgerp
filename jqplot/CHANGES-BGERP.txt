jqPlot 1.0.9 за bgERP
====================

Версии
- Default JQPLOT_VERSION остава 1.0.8r1250. Запазени са и 1.0.0r1012,
  и 1.0.8r1250. Setup::$version не се променя.
- 1.0.9 е добавена като отделна директория и опция в core_Packs.
- Последен официален tag: https://github.com/jqPlot/jqPlot/tree/1.0.9
  commit d96a669fbb729f4f51e2214688e54320411219af.
- Новостите според upstream changes.txt са step chart, enhanced pie legend,
  поправки в pointLabels, pieRenderer и преоразмеряването на barRenderer.
- Няма нов Composer пакет или външно CDN зареждане.

Доставка и лицензи
- Комплектът е построен от официалния source tag. Включва core, CSS,
  excanvas и всичките 31 plugin файла, всеки с minified вариант.
- tests/build.js използва официалния Gruntfile за реда на concatenation
  и обработката на source файловете. Не изпълнява examples или PHP build.
- Build зависимости само за разработка: uglify-js 3.19.3, clean-css 5.3.3.
  Те не се добавят към production, Composer или Git.
- Повторение, с отделна работна директория за build инструментите:
  npm install --prefix BUILD_TOOLS --ignore-scripts --no-audit --no-fund uglify-js@3.19.3 clean-css@5.3.3
  node jqplot/tests/build.js UPSTREAM_TAG_DIRECTORY OUTPUT_DIRECTORY BUILD_TOOLS/node_modules
- Нормалните JS файлове пазят source кода, minified вариантите са
  произведени от същия комплект. Старите renderers не се смесват с новите.
- Upstream позволява избор между MIT и GPL-2.0; тук се използва MIT.
  Запазени са пълният MIT лиценз и copyright.txt, включително attribution
  за jsDate, Ken Snyder (CC BY 3.0), sprintf и останалите вградени части.
  package.json е оригиналният upstream файл; водещ е текстът на лицензите.

Местни поправки
- В 1.0.9/plugins/jqplot.cursor.js са премахнати само "delete series" и
  "delete s". Те са невалиден синтаксис в upstream strict mode, а двете
  локални променливи вече са занулени. Поправката е и в build скрипта,
  за да се възпроизвежда при генериране на minified файла.
- В 1.0.0r1012/jquery.jqplot.js и .min.js е добавена проверка за наличие
  на $.browser преди стария IE/excanvas тест. При съвременния jQuery това
  поле липсва. Не се добавя глобален jQuery shim и IE пътят се запазва,
  когато старият jQuery предоставя полето.
- PHP адаптерът приема липсващите type/dir/log със съществуващите defaults
  и обработва празна хоризонтална серия без undefined offset.
- on_AfterRenderListTable връща заменения шаблон по референция, както
  изисква framework hook-ът. Преди това новата графика оставаше локална
  за метода и извикващият код запазваше старата таблица.

Проверки
- php jqplot/tests/versions.php: 132 проверки на PHP 7.4 и PHP 8.2.
  Всички версии, двата resource режима, наличие/избор на plugins,
  хоризонтални стойности, log axis, празни и непълни конфигурации,
  връщане на шаблона от плъгина.
- Старият PHP код възпроизвежда undefined offset при празна серия;
  старият plugin не подменя шаблона. След поправката тестовете минават.
- Browser: line, вертикални и хоризонтални bars, log axis, кирилица,
  нули, отрицателни/дробни стойности, две серии, етикети, 1000 точки,
  реално изрисувани canvas пиксели. Проверени са и трите версии на
  PHP 7.4/8.2 с jQuery 4.0.0 и съществуващия Migrate 4.0.2.
- 1.0.9 е проверена допълнително с глобалния jQuery default 1.11.2
  на двата PHP режима и с replot при ширина 360 px.
- Реалният plugin hook е визуализиран със синтетични отчетни данни
  на двата PHP режима. Проверено е превключване през core_Packs.
- Проверени са syntax на всички нови JS файлове и променени PHP файлове.
- За повторение в друга инсталация: използвайте тестов отчет с
  jqplot_Plugin или jqplot_Chart, изберете последователно трите версии,
  проверете оси, стойности, етикети, мащаби и повторно рисуване.

Ограничения
- Това е стара библиотека; няма по-нов официален tag след 1.0.9.
- Няма автоматична замяна с Chart.js, защото интерфейсите са различни.
- При jQuery 4 е необходим вече наличният jQuery Migrate; нов shim
  или промяна на глобалните jQuery настройки не се добавя.
- Празната серия не предизвиква PHP предупреждение, но jqPlot изисква
  данни, за да рисува. Plugin потокът не създава графика без записи.
- 1000 точки с етикети се рисуват осезаемо по-бавно от Chart.js.
- Редките plugin видове са проверени синтактично, не всички визуално.
  Не са проверени IE/excanvas, печат/PDF и всички бизнес отчети.
