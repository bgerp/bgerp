# pdfform - четене и попълване на формуляри

Пакетът чете и попълва формуляри в три вида файлове:

| Вид | Пример | Как се попълва |
| --- | --- | --- |
| PDF с полета (AcroForm) | Бланки с полета за попълване | Стойностите се записват в полетата по име |
| PDF без полета | Документ с "Име: ______" | Текстът се пише върху страницата по координати |
| Сканиран PDF или снимка (jpg, png, gif) | Скан на хартиена бланка | Като горния; текстът на страницата се разпознава с OCR |

Резултатът винаги е **нов** PDF файл; оригиналът не се променя.

## Инсталация

Полетата се обработват с Python библиотеката [pypdf](https://github.com/py-pdf/pypdf)
(лиценз BSD). **Инсталацията е автоматична**: при инициализация на пакета, ако pypdf липсва,
се създава собствен venv в `EF_VENDOR_PATH/pdfform` (от името на уеб потребителя, без root) и
пътят до интерпретатора се записва в `PDFFORM_PYTHON_PATH`. Това става по начина на `markitdown`:
venv с `--without-pip` и официалния standalone pip.

Изисквания към сървъра:

- `python3` >= 3.9 (стандартно в Ubuntu и Debian); ако липсва, инициализацията го показва в червено;
- достъп до интернет при инициализация за изтегляне на pip и pypdf;
- `pdftotext` и `pdftocairo` (poppler-utils) за текста и картинката на страниците;
- `tesseract` за сканираните формуляри (пътят и езиците се вземат от пакета `tesseract`, ако е инсталиран).

Ръчна инсталация, ако автоматичната не е възможна:

```bash
python3 -m venv /opt/pdfform
/opt/pdfform/bin/pip install "pypdf[crypto]>=5"
```

След това в настройките на пакета се задава `PDFFORM_PYTHON_PATH=/opt/pdfform/bin/python`.

## Използване от код

```php
// Страници, полета и текстът с позиции на избраната страница
$form = pdfform_Api::read($fh, 1);

// Попълване: полета по име и елементи по координати (проценти от страницата, от горния ляв ъгъл)
$res = pdfform_Api::fill($fh, array(
    'fields' => array('name' => 'Иван Петров', 'agree' => true),
    'items'  => array(array('page' => 1, 'x' => 30, 'y' => 12, 'width' => 40, 'text' => 'Текст')),
    'flatten' => true,
), 'form_filled.pdf');
```

Текстово поле, което се повтаря на няколко места, има в резултата от четенето `widgets` със
страницата и правоъгълника на всяко повторение; при попълване стойността се пише във всяко видимо
повторение. Скритите полета (флагове Hidden или NoView) имат `hidden` и не се рисуват при заключване.
Координатите са спрямо видимата (изрязаната) страница; страниците с CropBox, различен от MediaBox,
имат `cropped`.

При грешка резултатът съдържа `error`; при невалидни стойности или координати нищо не се записва,
а `errors` изброява всички проблеми.

`flatten` (по подразбиране `true`) прави стойностите част от страницата. Тогава текстът на
полетата се рисува с шрифт DejaVu Sans, затова кирилицата се вижда във всяка програма. При
`flatten=false` полетата остават редактируеми, но видът им зависи от шрифта на самия формуляр.

Динамичните XFA формуляри на Adobe нямат полета за попълване и се отказват.
