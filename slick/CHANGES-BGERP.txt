Slick 2.0.1
===========

Източник и лиценз
-----------------
https://github.com/kenwheeler/slick/releases/tag/v2.0.1
https://github.com/kenwheeler/slick/releases/tag/v2.0.0
https://github.com/kenwheeler/slick/tree/v2.0.1

Добавени са непроменените JS/CSS, шрифтове и loader от официалния tag v2.0.1
(commit ad3198e) в отделна директория по съществуващата js/css структура.
Запазени са MIT LICENSE, README и package.json. Няма Composer/npm инсталиране.
Зависимостта е наличният jQuery; upstream декларира >=1.8.0.

При проверката npm latest сочи 2.0.0, затова е използван официалният GitHub
release. Самият upstream tag v2.0.1 запазва текст 2.0.0 в JS header и
package.json. Те не са редактирани; RTL поправката от v2.0.1 е включена
и в slick.js, и в slick.min.js.

Новости и промени в bgERP
------------------------
- Клон 2 заменя премахнати jQuery API и поддържа jQuery 4. Има поправки във
  focus/blur, swipe, centerMode и ARIA labels; шрифтовете включват WOFF2.
- 2.0.1 задава dir=rtl върху самия слайдер при rtl:true, включително когато
  посоката не идва от HTML предшественик.
- Новата версия е достъпна в core_Packs. SLICK_VERSION остава 1.9;
  старите директории и техните файлове са непроменени.
- Досегашните bgERP настройки inner/out за стрелки и точки са пренесени в
  slick/lib/bgerp.css, зареждан само за 2.0.1. Upstream темата остава оригинална.
  Правилата за бутоните са ограничени до слайдера. Не се пренася глобалният
  стар selector button, нито неизползваният .outerArrowsaa.
- render() генерира уникален DOM id с префикс slick + id на CMS записа.
  Така един запис може да се вгради повече от веднъж в една страница. Старият
  драйвер повтаряше id и инициализираше само първото копие.
- Вече инициализираните елементи се пропускат. Липсващите полета в параметрите
  се обработват без PHP предупреждения. Без картинки и в plain text няма слайдер.
- Публичният render() API и формулярът на CMS драйвера са запазени.

Проверки
--------
php slick/tests/versions.php

50 проверки преминават на PHP 7.4.33 и 8.2.34: старият default, трите избора,
всички ресурси, празен вход, незадължителни полета, размери, контроли, autoplay,
уникални идентификатори и повторна инициализация. PHP lint, JS syntax и
redirect-catch проверката преминават.

Браузърни проверки с реалния slick_Driver и синтетични файлове във fileman:
- 1.8, 1.9 и 2.0.1 на PHP 7.4 и 8.2: по 23 проверки за три отделни слайдера,
  картинки, вътрешни/външни/изключени контроли и повторна инициализация;
  по 11 проверки за next, previous, dots, destroy/rebuild.
- Тест със стария HEAD драйвер възпроизвежда дефекта при повторен CMS запис;
  със същите данни новият драйвер инициализира и трите копия.
- 2.0.1 работи с локалния jQuery 4.0.0 + Migrate и с глобалния default jQuery
  1.11.2 без Migrate. Матрицата 23 + 11 проверки е повторена на двете PHP версии.
- Допълнително: RTL/variableWidth, autoplay/pause, клавиатурна стрелка и
  съдържание с ширина 320px. Проверени са видимите стрелки, точки и кирилица.
- Превключването между трите версии е изпълнено през core_Packs; след тестовете
  новата версия е оставена само в тестовата инсталация.

Повторение: създайте синтетични картинки; вградете един CMS запис повече от
веднъж, с inner/out/no контроли. Проверете независимата навигация, размерите,
autoplay и повторно рендериране. Превключете версията в core_Packs и повторете.

Ограничения
-----------
Проверено е в Chromium. Няма тест на физическо touch устройство, Safari/IE,
всички breakpoint комбинации, всички CMS шаблони или PDF печат.
DOM идентификаторите вече имат уникален суфикс; външни интеграции не трябва да
предполагат, че един CMS запис има един постоянен HTML id във всички вграждания.
Това не променя записаните CMS данни и не изисква миграция.
